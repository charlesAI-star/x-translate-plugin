X 翻译

在 X（Twitter）时间线上自动翻译外语推文

基本设置

控制翻译哪些推文、翻译成什么语言。

启用翻译
关闭后扩展不会翻译任何推文，也不会显示译文。
自动翻译可见推文
滚动到外语推文时自动翻译。关闭后，每条推文下方会显示「翻译」按钮。
目标语言
只翻译与目标语言不同的推文。
跳过已经是目标语言的推文
例如目标为中文时，不再翻译中文推文。
翻译引用推文
推文里嵌套的引用内容也会翻译。
翻译个人简介
在个人主页上翻译用户简介（默认关闭）。
显示翻译服务标签
在译文下方显示「本地」「Google」「AI」等来源。

翻译服务

选择由谁提供翻译。默认的「自动」会优先使用 Chrome 本地翻译。

「自动」优先使用 Chrome 本地翻译；如果模型还没下载，页面底部会提示点一次「启用本地翻译」（Chrome 要求用户手势才能下载模型）。未启用前会自动改用 Google，翻译不会中断。你可以在译文下方看到实际使用的服务。

Chrome 内置翻译按「源语言 → 目标语言」下载模型。第一次遇到日语、法语等语言时，页面底部会提示点一次「启用本地翻译」，下载几秒到几十秒后生效；之后会很快。需要 Chrome 138 或更高版本。也可以点下方「测试当前配置」预先下载英语模型。

这是 Google 翻译的免费网页接口，不需要 API Key，但可能因为请求过多而返回 429。遇到限流时，建议换用 Chrome 本地翻译或大模型。

Key 只保存在本机 chrome.storage.local，不会同步到云端。Ollama / LM Studio / Magpie 这类本地服务通常不需要真实 Key；Magpie 的默认网关是 127.0.0.1:3425，默认 Key 为 magpie。选择预设会自动填入地址和模型，仍可手动修改。点「自动检测本地服务」可以扫描 Magpie、Ollama、LM Studio、LiteLLM、One API 等常见端口，再点「获取模型」从服务的 /v1/models 读取模型或路由组。检测只填入设置，不会自动切换翻译服务；确认后点「保存设置」才会生效。

速度提示：翻译延迟主要取决于模型。名字里带 flash / mini / fast 的模型通常明显更快；带 pro / max / thinking 的推理模型会更慢。Magpie 的 auto/... 是路由组，可能比直接的 provider/model 多一层路由。翻译推文建议优先选轻量模型；在 Magpie 上可以先试 auto/glm-5.3-flash，auto/deepseek-v4.1-flash 质量好但通常更慢。

在 Azure 门户创建「Translator」资源后，从「密钥和终结点」页面获取 Key 与区域。免费层每月约 200 万字符。

不填邮箱也能使用，但额度更低。MyMemory 是翻译记忆库，质量不稳定，建议只作为备用。

测试翻译

高级

一般保持默认即可。

个人主页提前翻译
打开博主主页时，提前翻译前 12 条推文（仅大模型模式），滚动时更少等待；会略微增加模型调用。
最短翻译长度
少于这个字符数的推文会被跳过，避免翻译「lol」「+1」这类内容。
调试日志
在 X 页面控制台输出扫描和翻译过程，排查问题时使用。

隐私与说明

扩展只在 x.com、twitter.com 上运行，只读取时间线中的推文文本。使用 Google、大模型或 Microsoft Translator 时，推文文本会发送到你选择的服务；使用 Chrome 内置翻译时，文本留在本机。

本项目与 X Corp. 无关。译文由第三方模型生成，可能存在错误，请以原文为准。

如果你需要更完整的功能（整页翻译、PDF、字幕、更多站点规则），可以直接使用现成项目：Kiss Translator（开源） 或 沉浸式翻译。

版本 · 参考了 Kiss Translator 的 X 页面选择器思路。
